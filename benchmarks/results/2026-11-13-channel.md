# channel_ping_pong（channel 规格增补 C9，只报告，不进验收）

- 日期：2026-11-13（UTC+8）
- 编译器：zig c++（clang 20 + libc++）；-O2 -DNDEBUG；aw 为 C++14，asio（190a8d8）为 C++20
- 方法：同一单线程执行上下文（aw `manual_executor` / asio `io_context`）上一个发送协程、一个接收协程，
  容量 1，`use_awaitable`；预热 1000 次后测 1,000,000 条消息；`taskset -c 2`，5 次运行取中位数。

| 实现 | 每条消息 | 全局 operator new / 条 | 字节 / 条 |
| --- | --- | --- | --- |
| aw::channel（内部锁，缓存开） | 121.9 ns | 0 | 0 |
| aw::channel（缓存关，`AW_DISABLE_RECYCLING_ALLOCATOR`） | 139.8 ns | 2 | 120 |
| asio experimental::channel（无锁、非线程安全） | 283.2 ns | 0 | 0 |
| asio experimental::concurrent_channel（带锁） | 312.1 ns | 0 | 0 |

5 次原始值（ns）：aw 128.3 / 123.7 / 121.9 / 119.7 / 117.4；asio channel 283.2 / 290.2 / 280.5 / 288.5 / 279.1；
asio concurrent_channel 309.5 / 310.8 / 312.1 / 321.4 / 312.8；aw 缓存关 141.8 / 139.5 / 139.9 / 139.4 / 139.8。

说明：两边每条消息都要两次投递（唤醒对端 + 完成自己）。单线程下 aw 的锁无竞争。跨线程管道没有测，
那种场景的耗时主要取决于线程唤醒，不取决于 channel 本身。
